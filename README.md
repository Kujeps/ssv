# Бот приёма заявок

Telegram-бот: клиент оставляет заявку пошаговой анкетой, модераторы обрабатывают заявки по очереди,
админ видит всё и управляет процессом.

## Роли
- **Клиент** — любой, кто не админ и не модератор: анкета, повторно подать заявку нельзя, пока предыдущая не обработана.
- **Модератор** — получает «Поступила новая заявка» (без данных), нажимает «Взять заявку» и получает одну заявку
  (сначала те, кому удобно говорить сейчас по часовому поясу клиента, затем самые старые). Пока заявка не закрыта,
  следующую не выдают. На обработку — `HOLD_MINUTES` (1 час), потом заявка возвращается в очередь.
  Итоги: «Согласился», «Отказался» и «Мусор» (с обязательной причиной), «Не дозвонился» (заявка уходит в
  «Перезвонить позже», модератор может брать новые), «Вернуть в очередь» (с причиной). Свои заявки — в «Мои заявки».
- **Админ** — каждая новая заявка приходит ему целиком и сама обновляется; «Все заявки» (архив с фильтрами и поиском),
  модераторы, статистика, Excel, рекламные ссылки, рассылка. Модераторов добавляет кнопкой в боте.

## Заявка клиента
Короткий диалог: бот представляется помощником и спрашивает, как удобнее связаться — кнопки «Позвонить»,
«WhatsApp», «Telegram», «Max» (для тех, у кого нет российского номера: подойдёт любой международный номер
или ник в Max). Для Telegram номер не нужен, берётся @username. **Заявка создаётся сразу, как только
получен контакт**, и уходит в очередь; затем бот уточняет возраст (диапазон кнопкой или числом), город
(текстом) и пол (кнопкой) — ответы дописываются в заявку, карточки обновляются. Имя и @username берутся
из профиля Telegram. После этого клиент может дописать информацию о себе и пожелания обычным сообщением —
она попадёт в заявку. Перед репликами бот показывает «печатает…».
Тексты — `quick.py` (словарь `TEXTS`). Прежняя подробная анкета сохранена: `FORM_VARIANT=full`.

## Переписка менеджера с клиентом через бота
Менеджеру не нужно писать клиенту первым со своего аккаунта: бот пишет сам (клиент уже запускал его, так что
блокировки за спам нет).
- **Подключение.** Создайте группу, включите в ней «Темы», добавьте бота администратором (право «Управление темами»)
  и менеджера участником, затем отправьте в группе `/relay_here` (от админа). Либо задайте `RELAY_CHAT_ID` в `.env`.
  Отключить: `/relay_off`.
- **Тема на заявку.** Когда менеджер берёт заявку, бот создаёт тему «#N Имя · Город» с карточкой клиента и кнопками
  статусов (Согласился, Отказался, В работе, Не дозвонился, Мусор, Вернуть в очередь; причины пишутся прямо в теме).
  Вложения, присланные клиентом, пока заявка ждала в очереди, переносятся в тему.
- **Менеджер → клиент.** Всё, что менеджер пишет в теме (текст, фото, видео, голосовые, файлы, стикеры, геопозиция,
  контакты), уходит клиенту с подписью «Менеджер Дмитрий». Имя меняется командой `/name Имя`. Правка сообщения в теме
  правит его и у клиента. Реакция 👍 — доставлено; если клиент заблокировал бота, в теме появится «Не доставлено».
  Сообщение, начинающееся с `#`, — заметка для себя: клиенту не уходит, сохраняется в заявке.
- **Клиент → менеджер.** Ответы клиента появляются в теме: «👤 Имя: …».
- **Автоответ.** Вне рабочего времени (`WORK_HOURS`, по умолчанию 9-21 по Москве) клиент получает «передал менеджеру,
  ответим утром» — не чаще раза в 8 часов.
- **Закрытие.** Заявка вернулась в очередь или закрыта → тема закрывается; клиент написал снова (после «Согласился»/«Отказался»)
  → тема открывается; другой менеджер взял заявку → открывается та же тема.
- **Журнал.** Все сообщения (входящие, исходящие, заметки) пишутся в таблицу `relay_log` базы.

## Таблица модератора
«📋 Моя таблица» (или `/table`) — свои заявки по запросу: № · дата передачи · анкета · статус · комментарий ·
перезвонить · доп. информация (+ выгрузка в Excel с теми же колонками). Правка прямо в чате: статус (В работе,
Не дозвонились, Перезвонить, Согласился, Отказался, Мусор), комментарий (в том числе быстрой фразой одной кнопкой),
доп. информация, данные клиента (телефон, город, возраст и др.). Быстрый ввод: `#21 текст` — комментарий,
`#21+ текст` — доп. информация. Все правки пишутся в журнал заявки (кто, что, было → стало).
Часовой таймер действует только на только что взятую заявку («Взята»). «⏳ В работе» (клиент думает, исход пока не ясен),
«Не дозвонились» и «Перезвонить» остаются у модератора без таймера.

## Напоминания тем, кто не подал заявку
Включаются тумблером «🔔 Напоминания» в панели админа (по умолчанию **выключены**). Получают те, кто запустил бота,
но не оставил заявку (кроме отписавшихся, заблокировавших бота, админов и модераторов): через 1, 6, 24, 48, 72 и
96 часов после запуска, только с 10:00 до 20:00 по Москве, не более `REMINDER_BATCH` за проверку. Бросившим анкету и выбравшим способ связи без контакта — свои тексты. Под каждым сообщением кнопка «Не напоминать». Тексты и график — `reminders.py`, `config.py`.
Каждый новый человек, запустивший бота, приходит админу одной строкой (имя, @username, источник); повторные
`/start` не уведомляют, а пишутся в журнал. Тумблер «🚀 О запусках» — в панели админа. Все запустившие —
кнопка «📤 Excel запустивших» или «👤 Пользователи» (фильтры, поиск, Excel).

## Запуск
```
python -m venv .venv
.venv/bin/pip install -r requirements.txt      # на Windows: .venv\Scripts\pip ...
cp .env.example .env                            # впишите BOT_TOKEN и ADMIN_USER_IDS
.venv/bin/python bot.py
```
Обновление: `git pull`, затем перезапустить `python bot.py`. База (`leads.db`) мигрируется автоматически.

## Устройство
| Файл | Назначение |
|---|---|
| `bot.py` | точка входа, меню команд |
| `config.py` | настройки и константы (статусы, подразделения, часовые пояса, лимиты) |
| `db.py` | SQLite: заявки, очередь, модераторы, архив, статистика, Excel |
| `form.py` | подробная анкета клиента (вариант full): шаги, тексты, проверка ввода; разбор «27, Иркутск, мужчина» |
| `quick.py` | короткая заявка-диалог (вариант short): тексты, «печатает…» |
| `ui.py` | клавиатуры, карточки заявок, панели |
| `client.py` | клиентская часть (анкета, защита от повторной заявки) |
| `table.py` | таблица модератора и быстрое редактирование заявок |
| `staff.py` | модераторы и админ: очередь, архив, модераторы, статистика, ссылки, рассылка |
| `relay.py` | переписка менеджера с клиентом: темы в группе, пересылка сообщений и вложений, автоответ |
| `notify.py`, `jobs.py` | сообщения персоналу; таймеры (возврат, перезвон, напоминания) |

## Проверки
`python tests/run_all.py` — сквозные проверки на имитации Telegram (сеть и токен не нужны).
